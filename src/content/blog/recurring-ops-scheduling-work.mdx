Some work is never done: invoices, reports, renewals. This is a sample post – replace it with your own engineering write-up.

## Run it twice, get one result

Every recurring task is safe to repeat. If a run is interrupted, the next one picks up without doing the work twice.

## Notice when the world changes

Vendors change their forms without warning. When a page looks different from last time, the task pauses and asks for a review instead of guessing.

## Reliable by default

Small, boring, repeatable steps are what make recurring work trustworthy.
